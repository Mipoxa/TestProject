REST API для пошуку, бронювання та розрахунку вартості оренди конференц-залів.

Проєкт був розбитий на 4 шари:

TestProject.Entities - сутності без залежностей. Містить валідацію даних в сутностях.
TestProject.ClassLogic - покриває use cases, інтерфейси репозиторіїв, DTO та калькулятор, що використовується для розрахунку вартості по часових зонах (зони описані внизу).
TestProject.Database - реалізація репозиторіїв через Entity Framework Core та SQL Server, конфігурації сутностей.
Та API шар: контролери, middleware обробки виключень, Swagger, Program.cs.

Весь код був покритий тестами, що знаходяться в TestProject.Test

Поточні множники часових зон:

06:00–09:00 = −10% 
09:00–18:00 = +0%
12:00–14:00 = +15% 
18:00–23:00 = −20% |
23:00–06:00 = +0%

(Якщо бронювання перетинає кілька зон одночасно (наприклад, 11:00–15:00), вартість рахується окремо по кожному погодинному відрізку і сумується.)
